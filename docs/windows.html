Install in four steps

  1. Download Mercury

    Click Download for Windows above. Your browser saves Mercury-Setup-0.1.1.exe in your Downloads folder. It's 118 MB, so give it a minute.

    If your browser warns you. Mercury is new and isn't signed with a paid certificate yet, so your browser may say the file isn't commonly downloaded. That's expected.

    • Edge: in the downloads box, click the three dots next to the file, then Keep, then Show more, then Keep anyway.
    • Chrome: in the downloads box, click Keep.
  2. Open the file

    Click the file in your browser's downloads, or open your Downloads folder and double click Mercury-Setup-0.1.1.exe.

    Windows then shows a blue box saying Windows protected your PC. It shows this for any app it hasn't seen many times before.

    You don't need an admin password. Mercury installs in a few seconds and opens by itself.

  3. Choose how Mercury thinks

    On the welcome screen, keep Use Mercury's free AI selected and click Start using Mercury. There's no account to make. You get 40 messages a day. If you have an Anthropic API key, you can use that instead.

  4. Find Mercury any time

    The chat opens in the bottom right corner. When you hide it, Mercury keeps running by the clock in the taskbar. To bring it back:

    • Press Alt\ (the backslash key, usually just above Enter).
    • Or click the Mercury icon by the clock. If you can't see it, click the ^ arrow next to the clock. You can drag the icon onto the taskbar so it always shows.

    Mercury starts with Windows, so it's always ready. You can turn that off in its Settings.

Everything Mercury does on your PC, like saving a note or running a command, shows an Approve or Deny card first. Opening an app or setting a timer just happens, because you can see it straight away. Read more on the safety page.

Open PowerShell from the Start menu and run Get-FileHash $HOME\Downloads\Mercury-Setup-0.1.1.exe. The long code it prints should match this fingerprint exactly:

Privacy

With the free AI, your messages pass through a small Mercury server to Anthropic and aren't stored. The server only keeps daily counts so everyone gets a fair share. The full details are in the privacy policy.

Uninstall

  1. Right click the Mercury icon by the clock and choose Quit Mercury.
  2. Open Settings, then Apps, then Installed apps. Find Mercury, click the three dots, then Uninstall.
  3. Optional: delete Mercury's settings folder by typing %APPDATA%\Mercury into the File Explorer address bar. Your recordings (in Videos, Mercury Recordings) and notes (in Documents, Mercury) are yours to keep or delete.
