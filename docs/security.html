Safety and security

How Mercury keeps you safe: approvals, protections and how to check your download.

Last updated 3 November 2026

Mercury can see your screen, hear your voice and do things in your apps, so I've built it to be careful by default. This page explains how.

The ground rules

Before Ask Mercury can see or hear anything, Mercury shows you these rules and asks you to agree:

  • It sees your screen only when you ask. Each question sends one screenshot to your AI. Turn the eye off for private screens, like banking.
  • Listening is off until you turn it on, and a red dot shows while it's on.
  • Nothing is sent without you. Emails need your Approve. Messages are typed in for you to send.
  • Private files stay private. It asks before reading key, password or history files, and before opening links that carry data.
  • It's visible. The chat shows up in screen shares unless you hide it for privacy, and it isn't for cheating or secret recording.

Actions need your approval

Looking things up runs freely. Anything that writes files, runs commands, or sends, creates, edits or deletes in your apps shows an Approve or Deny card first. You can say "yes" or "no" out loud. "Always allow" applies to one tool only, and never overrides the protections below.

Protection from tricks

A web page, email or document could contain hidden text meant to trick an AI into doing something you didn't ask for (called prompt injection). Mercury always asks you before:

  • reading files that hold keys, passwords or private history (for example ~/.ssh, keychains, browser data, shell history, .env files);
  • searching your whole home folder;
  • opening a web address that carries data in it, which is a common way to leak information.

Your accounts and keys

  • Mercury never asks for or stores your passwords. It works with the apps and browser you're already signed into.
  • Claude Code keeps its own sign in details in your Keychain, and Mercury never sees them.
  • An API key you add is stored in the macOS Keychain, never in a file.

Inside the app

  • Mercury's helper for Ask Mercury listens only on your own Mac (127.0.0.1) and needs a random secret that changes every launch, so other devices and websites can't use it.
  • The app uses Apple's hardened runtime and asks only for the system permissions it needs: camera, microphone and automation.
  • Speech recognition and Whisper run on your Mac; audio is never uploaded.

Check your download

Every release publishes a SHA256 fingerprint on the download page and on GitHub. In Terminal, run shasum -a 256 ~/Downloads/Mercury-*.dmg and compare. If they don't match, don't open the file. Only download Mercury from this site or its GitHub releases.

Early versions are signed but not yet notarised by Apple, so macOS warns the first time you open them. Notarisation (Apple's malware check) is on the way. Until then, the fingerprint and the public source code are how you can check the download.

Report a security problem

Please report it privately through GitHub's private vulnerability reporting, not in a public issue. Include what you found and how to reproduce it. I'll reply as soon as I can and credit you if you'd like.
